# Reglas y Configuraciones del Proyecto

## Unidades REM

El valor base para la unidad `rem` en este proyecto es de `12px`.

## Fuentes

La fuente principal utilizada en todo el documento es 'Work Sans'. Se recomienda establecer esta fuente a nivel global para evitar repeticiones.

## Iconos

Los iconos SVG deben ser insertados directamente en el HTML para facilitar la estilización con CSS.
