# Reglas de Estilo y Buenas Prácticas

Este documento describe las reglas de estilo y las buenas prácticas a seguir en el desarrollo de este proyecto web.

## HTML
- Utilizar semántica HTML5.
- Indentación de 4 espacios.
- Nombres de clases en kebab-case.

## CSS/SCSS
- Utilizar SCSS para estilos.
- Organización de archivos por componentes o secciones.
- Variables para colores, fuentes y tamaños.
- Nombres de clases en kebab-case.

## JavaScript
- Utilizar ES6+.
- Indentación de 2 espacios.
- Nombres de variables en camelCase.
- Comentarios claros y concisos.

## Optimización y SEO
- Optimización de imágenes.
- Minificación de archivos CSS y JS.
- Uso de etiquetas meta adecuadas.
- Estructura de encabezados (h1, h2, etc.) coherente.

## Accesibilidad
- Uso de atributos `alt` en imágenes.
- Navegación por teclado.
- Contraste de colores adecuado.
